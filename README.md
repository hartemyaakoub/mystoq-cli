# mystoq-cli

> Manage your Mystoq COD store from the terminal.

[![Mystoq](https://img.shields.io/badge/Mystoq-mystoq.com-1d4ed8)](https://mystoq.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/hartemyaakoub/mystoq-cli/main/bin/mystoq -o /usr/local/bin/mystoq
chmod +x /usr/local/bin/mystoq
```

## Use

```bash
export MYSTOQ_API_KEY=...
export MYSTOQ_TENANT=your-store

mystoq products list
mystoq orders list
mystoq wilayas
mystoq ping
```

## Why?

Some workflows are faster from a terminal than a dashboard:
quick stock checks, bulk listings, scripted automation, daily cron jobs.
